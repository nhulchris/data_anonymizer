Technique guide

What each technique does, in plain terms.

Substitution

Replaces the value with a realistic, made-up one of the same type. The same real value always gets the same replacement.

Daniel Carter → Brittney Cameron

Pseudonymization

Replaces the value with a consistent fake value — the same input always produces the same output, which keeps relationships between records intact.

Daniel Carter → Brittney Cameron (same, every time)

Partial masking

Hides part of the value while keeping its format recognizable.

j.smith@gmail.com → j*****@gmail.com

Generalization

Reduces precision while keeping the value useful.

1990-05-15 → 1990

Nulling

Removes the value entirely.

123-45-6789 → (blank)

Hashing

Converts the value into a scrambled, fixed-length code using a one-way function — the original can't be recovered from it, but the same input always produces the same hash.

daniel.carter@example.com → 9f86d08188...
